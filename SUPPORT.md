# Support

## Where to get help

| Need | Channel |
| --- | --- |
| Usage question, design discussion, or roadmap | GitHub Discussions (enable in repository settings before publishing) |
| Bug report | GitHub Issues using the bug report template |
| Feature proposal | GitHub Issues using the feature request template, with a linked spec |
| Security vulnerability | See [SECURITY.md](SECURITY.md) — private reporting only |
| Conduct concern | See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

## Before asking

1. Read [README.md](README.md) and the status banner — this repository currently
   contains a specification, not a runnable server.
2. Read [docs/development-method.md](docs/development-method.md) if your question
   is about SDD/ATDD workflow.
3. Search existing issues and discussions first.

## What to include

For a bug: MCP protocol version, host name and version, transport (stdio or
Streamable HTTP), exact request/response, and the acceptance scenario ID (`AT-*`)
that failed. Never paste credentials, tokens, or personal data.

## Response expectations

This is a small volunteer-maintained project. There is no paid support tier, no
SLA, and no private support email. Public channels are preferred so answers
remain searchable for everyone.
